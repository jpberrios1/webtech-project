# User Stories 

1. As a member (host), I want to register a property with its address and shared areas, so that I can use it as a base for publishing my available rooms.

2. As a member (host), I want to publish a listing with the room’s rent, availability, and photographs, so that visitors can clearly see what I am offering.

3. As a visitor, I want to view the complete details of a listing, including photos, house rules, reviews, and amenities, so that I can decide whether the property suits my needs before creating an account.

4. As a member (seeker), I want to include an introduction message when submitting an application, so that the host can get to know me and feel more comfortable considering my application.

5. As a member (seeker), I want to withdraw an application, so that the host does not waste time considering me if I am no longer interested.

6. As a member (host), I want to cancel or reschedule a visit, so that I can avoid conflicts with my schedule.

7. As a member (host), I want to preview a draft of my listing, so that I can make sure all the information is complete and accurate before publishing it.

8. As a moderator, I want to take down listings, so that the platform remains safe and free from scams and inappropriate content.

9. As a member (seeker), I want to leave a review of a property after visiting it, so that other users can know whether the property is worth considering.

10. As a moderator, I want to review listings reported by users, so that I can take the necessary action against listings or hosts that violate the platform’s rules.

11. As a member (seeker), I want to save listings that interest me, so that I can easily find and review them later.

12. As a member (host), I want to review all the applications submitted for my listing, so that I can choose a tenant I feel comfortable with.

13. As a member, I want to report a listing that appears to be fraudulent or misleading, so that I can alert the moderators and help protect other users.

14. As a member (host), I want to accept an application after a successful visit, so that I can secure the tenant and have the system automatically reject the other pending or shortlisted applicants.

15. As a member (host), I want to select an applicant I am interested in and schedule a visit with them, so that I can meet them in person before making a decision.

16. As a moderator, I want to manage the neighborhood and amenity catalogs, so that information remains standardized and users do not create duplicate entries.

17. As a member (seeker), I want to confirm the date and time of a visit proposed by the host, so that I can ensure my attendance and move forward with my application.

18. As a visitor, I want to filter listings by neighborhood, maximum rent, availability date, and amenities, so that I can quickly find options that match my budget and needs.

19. As a member (seeker), I want to check the status of my submitted applications, so that I can keep track of the progress of my room search.

20. s a member (host), I want to withdraw my own listing at any time, so that I can cancel the rental process if I decide not to rent out the room anymore.
