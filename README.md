# Roomies

Roomies is a web platform designed to match people who have a free room in a shared home with people looking for a place to live. Rather than treating shared housing as a pure transaction, Roomies facilitates the entire matching journey: browsing and searching listings, applying privately, scheduling visits, and finalizing roommate selections.

Project developed for the **Web Technologies**, Faculty of Engineering and Applied Sciences, **Universidad de los Andes**.

## Assignment 1 Deliverables

This repository contains the foundation work for Assignment

1. **Landing Page:** A responsive, accessible static HTML/CSS landing page built with Bootstrap 5.

2. **User Stories:** Complete specifications covering visitors, members (hosts and seekers), and moderators.

3. **Domain Model:** Relational database schema diagram created in dbdiagram.io -> [[Link to page]](https://dbdiagram.io/d/6aa6a960957fec6d5bdf368c)

4. **Design Decisions Document:** Architectural overview explaining model design, entity lifecycles, and assumptions.
